PsychoLog – Version 1.1

INHALT
- index.html: vollständige Anwendung mit zehn Modulen und Formulierungsbibliothek
- manifest.webmanifest: PWA-Metadaten
- sw.js: Offline-Caching der App-Dateien (Cache-Version 1.1)

NEU IN VERSION 1.1
- Formulierungsbibliothek mit anklickbaren, beobachtungsnahen Satzbausteinen für Kontakt, Kommunikation, Antrieb, Psychomotorik, Affekt und Sozialverhalten.
- Ausgewählte Bausteine werden in das Feld „Konkrete Verhaltensbeobachtung“ eingefügt und können vor der Berichtserstellung angepasst werden.
- Berichtserstellung formuliert strukturierte Merkmale in lesbare Sätze und übernimmt narrative Freitextangaben unverändert (abgesehen von einem fehlenden Satzschlusszeichen).
- Keine automatische Interpretation oder Ergänzung von klinischen Tatsachen.

START
1. ZIP entpacken.
2. Für PWA-Installation und Offline-Betrieb den Inhalt des Ordners psycholog_v1 auf einen HTTPS-Webhost (z. B. GitHub Pages) hochladen.
3. iPhone: Website in Safari öffnen > Teilen > Zum Home-Bildschirm.
   Android: Website in Chrome öffnen > Installieren / Zum Startbildschirm hinzufügen.

DATENSCHUTZ / GRENZEN
- Formulareingaben werden nicht in localStorage, Cookies, Datenbank oder Server gespeichert.
- Keine externe KI und keine Netzwerkübertragung von Berichtsinhalten.
- Eingaben und Ausgabe existieren nur im Arbeitsspeicher des geöffneten Tabs. Beim Neuladen/Schließen gehen sie verloren.
- Service Worker speichert ausschließlich Programmdateien, keine Formulareingaben.
- TXT-Export und Kopieren erfolgen nur nach ausdrücklicher Betätigung.
- Bis zur institutionellen Freigabe ausschließlich fiktive Beispieldaten verwenden.
- Kein Ersatz für das freigegebene Krankenhaus-Dokumentationssystem.

QUALITÄTSHINWEIS
Freitext wird bewusst nicht inhaltlich umgeschrieben. Prüfe jeden Entwurf auf Richtigkeit, Vollständigkeit, zeitliche Reihenfolge und klare Trennung zwischen eigener Beobachtung, Patientenaussage und pflegerischer Einschätzung.
